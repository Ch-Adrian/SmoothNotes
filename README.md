# SmoothNotes

## Nazwa aplikacji: 
SmoothNotes

## Opis: 
Aplikacja będzie pozwalała użytkownikowi tworzyć i zapisywać notatki tworzone na szybko w celu porządkowania i przechowywania zebranych informacji. W szczególności obszarem zastosowanie byłoby tworzenie notatek do nauki. Zbieranie informacji z książek i z 

## Planowane funkcje:
Dodawanie i edycja tekstu.
Dodawanie i robienie zdjęć.
Przesyłanie notatek.
Dodawanie danych geolokacji.
Tworzenie różnych rodzajów notatek w różnych formach np. lista, tabela, tekst.
Szyfrowania notatek.
Ekstrakcji tekstu ze zdjęć lub zakreślania informacji na zdjęciach i zapisywaniu ich.
Tłumaczenie tekstu.

## Planowane zaawansowane funkcje:
Wersja rozproszona dla zaawansowanego projektu.
